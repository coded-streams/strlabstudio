SDK & Integration
Connect Str:::Beam to your application using the REST API or one of the SDK clients.
Add the Str:::Beam starter to auto-configure a FlinkSqlGatewayClient bean using your tenant credentials. Replace values below with your actual keys.
pom.xml
<!-- Str:::Beam Spring Boot Starter --> <dependency> <groupId>io.codedstreams.strbeam</groupId> <artifactId>strbeam-spring-boot-starter</artifactId> <version>1.0.0</version> </dependency>
application.yml
strbeam: engine-url: YOUR_ENGINE_URL tenant-key: YOUR_TENANT_KEY api-key: ${STRBEAM_API_KEY} # inject from env catalog: YOUR_CATALOG session: auto-create: true parallelism: 1
Java — submit a streaming statement
@Autowired private StrBeamClient client; public void runPipeline() { // 1. Open a session (expires after 25 h of inactivity) SessionHandle session = client.openSession(); // 2. Submit Flink SQL OperationHandle op = client.submit(session, """ INSERT INTO kafka_sink SELECT user_id, SUM(amount) AS total FROM payments_source GROUP BY user_id """); // 3. Poll until RUNNING client.waitForRunning(session, op); // 4. Heartbeat every 30 s to keep session alive scheduler.scheduleAtFixedRate( () -> client.heartbeat(session), 0, 30, SECONDS); }
Install
pip install strbeam-python-sdk
Submit SQL
from strbeam import StrBeamClient import os client = StrBeamClient( engine_url = "YOUR_ENGINE_URL", tenant_key = "YOUR_TENANT_KEY", api_key = os.environ["STRBEAM_API_KEY"], ) session = client.open_session() op = client.submit(session.session_id, statement=""" SELECT window_start, COUNT(*) AS cnt FROM TABLE(TUMBLE(TABLE events, DESCRIPTOR(event_time), INTERVAL '1' MINUTE)) GROUP BY window_start """) # Fetch result pages for row in client.fetch_all(session.session_id, op.operation_id): print(row)
1. Open a session
curl -X POST YOUR_ENGINE_URL/api/v1/sessions \ -H "Authorization: Bearer $STRBEAM_API_KEY" \ -H "Content-Type: application/json" \ -d '{}' # Returns: {"sessionId":"...","catalogName":"...","expiresAt":"..."}
2. Submit a statement
curl -X POST YOUR_ENGINE_URL/api/v1/sessions/{sessionId}/statements \ -H "Authorization: Bearer $STRBEAM_API_KEY" \ -H "Content-Type: application/json" \ -d '{"statement":"SHOW CATALOGS;"}'
3. Heartbeat (call every 30 s to keep session alive)
curl -X PUT YOUR_ENGINE_URL/api/v1/sessions/{sessionId}/heartbeat \ -H "Authorization: Bearer $STRBEAM_API_KEY"
